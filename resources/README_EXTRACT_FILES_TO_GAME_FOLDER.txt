DLSSG TO FSR3 INSTALLATION

1. Extract every file and folder from this archive into the folder containing
   the game executable.
2. Double-click windows_install.bat.
3. Enter the number for the required installation mode. Press Enter to use
   the default mode.

After installation, windows_install.bat becomes windows_uninstall.bat.
Double-click windows_uninstall.bat to remove the mod and restore backed-up
files.

Linux and Proton users should run:

    bash linux_install.sh

The script becomes linux_uninstall.sh after installation. Run it with bash to
remove the mod.

Choose OptiScaler mode AFTER installing Optiscaler. It will replace the included
dlssg_to_fsr3_amd_is_better.dll.

Do not use this mod in multiplayer games.
